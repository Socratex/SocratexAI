## 🚦 Limits

🚦 Routing is an agent decision, not a parent-model auto-switch mechanism.
Select native roles when exposed; otherwise explicitly pass model, effort and
role instructions using fresh context. Custom role files take precedence over
spawn model settings. To request a higher supported effort than a fixed role,
use the explicit-model route with its instructions instead of claiming the role
file was overridden. A task name alone never activates a custom role.

🔒 Source changes preserve approval, diagnostics, tests, canonical finalization
and AUTO boundaries. No paid APIs, model installations, global settings changes
or custom production orchestration were introduced. Current model availability
must be checked when installing elsewhere. No end-to-end quota, latency or
quality improvement was benchmarked.
